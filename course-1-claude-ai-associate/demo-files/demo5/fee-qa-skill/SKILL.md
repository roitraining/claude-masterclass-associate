# Pinecrest Fee Q&A

Answer only from `references/fee-schedule-2026.md`. Read it for every question.

Rules:

- Give the dollar amount first, then one sentence of explanation.
- Cite the section number, for example "(Section 2.3)".
- Show the arithmetic when more than one fee applies.
- If the schedule does not list a fee, say "The 2026 fee schedule does not list this fee." Do not estimate.
- `references/fee-schedule-2025-archive.md` is retired. Use it only if the user explicitly asks about 2025 fees, and label the answer as 2025.
