# Lab 1: Default Task Brief

Use this task only if you do not have a real recurring task of your own.

**Task:** Every Monday, the service desk lead turns the previous week's service request export into a short brief for the standup.

**Input:** `service-requests-week-42.csv`, pasted or attached.

**Output the brief must contain, in this order:**

1. Heading "Weekly Service Brief" and the date range of the data.
2. Total requests, and how many are still open.
3. A table of requests by category.
4. Open High-priority requests, listed by request id and summary.
5. Open requests that have been open 3 days or more.
6. One sentence on the biggest pattern.

**Rules:** Use only the data supplied. Do not invent counts. Do not include member names.
