# Lab 3: Artifact Prompt

Paste into a new chat. Adjust the brief to match your Lab 1 Skill if you built a different one.

```
Build an artifact called Service Desk Brief. It has a text box where the user pastes service request rows in CSV form, a Brief button, and a results area. When the button is pressed, the artifact sends the rows to Claude and shows:
- Total requests and how many are open
- Requests by category, as a table
- Open High-priority requests
- Open requests older than 5 days
- One sentence on the biggest pattern
Use only the pasted data. Never invent a count. Show the note "Draft only. A person checks the numbers." Do not show member references in the results.
```

Then test it by pasting the rows from `service-requests-4weeks.csv`.
