# Pinecrest Meeting Recap

Write every recap using the layout in `references/recap-template.md`. Read that file first.

Then check the notes for these two situations and read the matching file only if the situation applies:

- The notes quote an advisor or staff member talking about returns, rates of return, guarantees, or product performance. Read `references/compliance-flags.md` and add a "Compliance review" line to the follow-up flags.
- The notes mention a complaint, a dispute, or possible fraud. Read `references/escalation-contacts.md` and name the correct contact in the follow-up flags.

If neither situation applies, do not read those two files.

Rules that always apply:

- If a due date is not in the notes, write "Not set".
- Never invent an owner. If no owner is named, write "Unassigned".
- Keep the whole recap under 250 words.
