# Data Plugin Dashboard (Take-Home)

`loan-applications.csv` holds 60 fictional loan applications from six months, with planted data problems. Part of the job is finding them.

Planted problems (do not read until you have run your own cleaning pass): a lowercase branch name, a misspelled branch name, a missing amount, a negative amount, an impossible date (September 31), an implausible days_to_decision value, a duplicate application ID, a status with a trailing space, and a missing credit score.
