# Morning Operations Briefing: Task Prompt

Paste the text between the lines into the scheduled task.

---
Read every file in the folder `scheduled-task/daily-ops-feed` that is dated today or, if none is dated today, the most recent date available. Write a one-page briefing to `scheduled-task/briefings/briefing-<date>.md` with these sections:

1. Headlines (three bullets at most)
2. Exceptions by branch (a small table)
3. Member Care cases older than 14 days
4. System issues and tonight's maintenance
5. Items that need a human decision today

Rules:
- Use only the files in the daily-ops-feed folder.
- Write only to the briefings folder.
- Do not change, move, or delete any other file.
- End with a line that starts with "Sources:" followed by the file names you read.
- If a file is missing or unreadable, say so in the briefing instead of skipping it silently.
