# Lending Approval Matrix

| Loan size | Secured | Unsecured |
|---|---|---|
| Up to $15,000 | Loan officer | Loan officer |
| $15,001 to $75,000 | Senior loan officer | Lending manager |
| $75,001 to $250,000 | Lending manager | Credit committee |
| Over $250,000 | Credit committee | Not offered |

## Exceptions
- A member with a credit score below 620 needs one approval level above the table.
- Any exception to the matrix must be written and signed by the Chief Lending Officer.
